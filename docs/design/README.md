# Design

## Design System

The design system should help the product feel operational, trustworthy, and scalable across many modules.

## UX Principles

- Make navigation obvious.
- Reduce cognitive load in administrative flows.
- Keep important actions visible.
- Present dense business data with strong hierarchy.
- Ensure responsive behavior on desktop and mobile.

## Motion Principles

- Use motion to support orientation, not decoration.
- Keep transitions purposeful and restrained.
- Animate state changes that help users understand what changed.

## Visual Direction

The product should look like a serious business platform, not a marketing site. Visual clarity, spacing discipline, and predictable components matter more than novelty.
