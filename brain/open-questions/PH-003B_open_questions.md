## Notes

- These questions include inherited PH-003A questions and PH-003B domain questions.
- PH-003C must preserve unresolved questions as schema decisions marked `OPEN`.
- No implementation should assume answers that are not approved.
- MVP go-to-market is manual / voz a voz / initial promoter team; this must not be interpreted as public marketplace, self-service checkout, or public affiliate system.
- Domain strategy reserves the root domain `nombre.pro` for a future owner profile site; MVP operational landings should preferably use subdominio targets such as `vsl.nombre.pro`, `shop.nombre.pro`, or `[producto].nombre.pro`.
