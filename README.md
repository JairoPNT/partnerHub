# PartnerHub

Repositorio base para documentar y construir la plataforma SaaS para empresarios de multinivel.

## Estructura

- `docs/` contiene la documentacion de soporte y definicion de alto nivel.
- `app/web` contiene la aplicacion Next.js desplegable.
- `app/api`, `app/infra` y `app/packages` quedan reservadas para expansion tecnica.
- `Dockerfile` en la raiz es el punto de entrada para despliegues en Easypanel.
- Los documentos raiz `Proyecto_*.md` quedan como referencia historica.

## Orden de trabajo

1. Concepcion de la idea
2. Requerimientos funcionales y no funcionales
3. Primer incremento de construccion
