# Automation

## Automation Strategy

Automation should reduce manual work without hiding business logic.

## n8n

n8n is a strong candidate for orchestrating repeatable workflows such as notifications, lead routing, approvals, and integration triggers.

## AI

AI features should be applied carefully and should always respect tenant boundaries, user permissions, and business sensitivity.

Good AI use cases include:

- content assistance
- operational summaries
- support drafting
- workflow suggestions
- data classification support

## Automation Principles

- Keep automations observable.
- Store important automation outcomes.
- Avoid automations that silently mutate critical business records.
- Make retries and failures visible to operators.
